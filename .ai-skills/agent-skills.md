# Web Architecture Agent Skills

## Architecture Guidelines
- **Single Page Application with Modular Router**: Clean hash or state-driven routing with instant scroll-to-top on route change.
- **Formspree + Privyr Frontend Form Processing**: Real-time form validation, payload construction, and graceful error/success handling.
- **Distributor Locator**: Interactive filtering, geo-sorting, distance calculator, and stock availability indicators.
- **SPA Deployment Ready**: Clean Vite configuration with full index.html fallback compatibility for Vercel and cPanel deployments.
